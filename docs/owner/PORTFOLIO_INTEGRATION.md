# Portfolio integration

The current distribution depends on NumPy, SciPy and Matplotlib; it declares no runtime dependency on another portfolio repository. The interfaces for reuse are cycle/capacity arrays, explicitly described CSV/history records, fitted results and reproducible evidence. Do not pass a browser proxy output into a scientific workflow as measured data. For a shared study, define a versioned input/output schema and immutable source commits; retain raw inputs, units, transformations, licenses, expected failure cases and separate native/browser provenance. Require tests at the boundary and an independent measured-data validation plan before extending claims. The current synthetic fixture labels are not a cross-project benchmark. [Roadmap](../../ROADMAP.md) distinguishes reusable documentation work from exploratory scientific coupling.

This public document includes only public project references. Operational inventories and any private research material remain in appropriately restricted records, outside public portfolio synthesis.
