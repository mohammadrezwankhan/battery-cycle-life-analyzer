# Architecture and execution boundaries

The installed distribution contains `bcla*` and exposes the `bcla` console command. Native analysis uses NumPy, SciPy and Matplotlib. Checkout-only examples, data, notebook and static Pages assets are separate working surfaces. There is no model server, database or browser-to-Python execution bridge in this source. ## Native analysis flow

1. `datasets` produces seeded synthetic traces, reads a single-cell CSV/TSV, or loads a long-form table with per-cell metadata and optional interval history.
2. `core` receives numerical cycle and capacity arrays. The direct fitter does not normalize or sort them; temporal validation sorts by cycle and keeps duplicate cycle groups together.
3. Late-cycle validation chooses a family, then `select_model_by_validation` refits that family to all observations. `best_model` instead selects by an in-sample diagnostic.
4. `FitResult` stores arrays, parameters, covariance and fit diagnostics. EOL scans a finite grid; the bootstrap refits one selected family and withholds bounds after any failed or censored replicate.
5. `viz` returns Matplotlib objects; the CLI writes `bcla_demo.png` in the current working directory. Metadata such as temperature, C-rate, protocol, timestamps and duty-cycle intervals is preserved and summarized by loaders. It is not automatically a regressor or damage accumulation input to the capacity-fade functions. Keep the observation table and provenance beside the arrays. ## External data and presentation

`examples/oxford_energy_trading.py` is an opt-in adapter: it downloads two allowlisted Oxford files for one selected cell, canonicalizes profile timestamps, converts measured discharge throughput to EFC, and uses the same empirical fitting machinery. Its local text loader can be tested without a download. It is an example module, outside the installed `bcla*` package set. [examples/oxford_energy_trading.py:25–108](https://github.com/mohammadrezwankhan/battery-cycle-life-analyzer/blob/02ed161bded286dad4b3624961430a564715c782/examples/oxford_energy_trading.py#L25-L108) [examples/oxford_energy_trading.py:123–257](https://github.com/mohammadrezwankhan/battery-cycle-life-analyzer/blob/02ed161bded286dad4b3624961430a564715c782/examples/oxford_energy_trading.py#L123-L257) [pyproject.toml:57–58](https://github.com/mohammadrezwankhan/battery-cycle-life-analyzer/blob/02ed161bded286dad4b3624961430a564715c782/pyproject.toml#L57-L58)
