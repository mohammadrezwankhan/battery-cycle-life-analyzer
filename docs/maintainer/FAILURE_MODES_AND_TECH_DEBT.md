| Finding | Consequence | Current handling / proposal |
| --- | --- | --- |
| Package/runtime/changelog release identity differs | A version string alone cannot identify the analyzed code | Pin source; BCLA-01 aligns metadata with an explicit release decision |
| Simple versus long-form normalization reference differs | Unsorted input can change the scaling and comparability of results | Document both references; preserve raw measurements; BCLA-02 adds explicit preprocessing contracts |
| Metadata history accepts independent rows without interval overlap/physical consistency checks | Preserved context may be mistaken for validated aging exposure | Keep metadata separate from model inputs; BCLA-02 proposes semantic validation |
